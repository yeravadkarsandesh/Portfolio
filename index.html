Projects Here you will find personal project that I created that based on my undergraduate skills.

Supermarket website

This is a small e-commerce website named Balaji Supermarket, developed using JSP (Java Server Pages) and Servlets, with custom CSS for styling and MySQL as the backend database. It provides a seamless user interface and allows users to explore products, add items to their cart, and make purchases efficiently.

Login Page

The login form could represent the user authentication system of your e-commerce website. It serves as a gateway for users to access personalized features such as viewing their cart, placing orders, and managing their account details. By using JSP and Servlets, login validation is integrated with the MySQL database, ensuring secure user authentication and seamless data flow between the front-end and back-end.

Cart

This is the cart page of a supermarket website, whereusers can view, manage, and finalize their selected products before placing an order. The layout features a clean and intuitive design, displaying each product with an image, name, price, quantity, and a "Remove" button for easy modification. On the right side, a summary box shows a concise breakdown of all cart items along with their individual prices. The total amount is clearly calculated at the bottom, and a “Place Order” button allows users to proceed with their purchase. This user-friendly interface ensures a seamless shopping experience with easy access to essential cart controls.

Admin Dashboard

Secure access for authorized admins to efficiently manage the store. From this panel, admins can add or update products, track customer orders, and keep the store running smoothly. Everything needed to control the backend, all in one place! With a clean and user-friendly interface, navigation is quick and simple. Admins can monitor store performance and ensure product availability. This page acts as the control center for seamless store operations.
